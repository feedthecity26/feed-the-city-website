# Opportunity Day Huntsville

Public verification repository for a Huntsville, Alabama community initiative organized by **Levon Harper**.

## Mission
Build a practical local event that combines immediate assistance with pathways to employment, housing/recovery resources, résumé help, and legitimate entrepreneurship opportunities.

## Transparency
This repository is intended to document the project as it develops. Partnerships, event dates, funding arrangements, and impact claims should be published only when they can be verified.

**Important:** This project is not presented as a 501(c)(3) organization. It is also not represented as affiliated with Tango Charities or its existing **Feed The City** program in Huntsville. The public-facing working name is **Opportunity Day Huntsville** to reduce confusion.

Open `index.html` for the public project overview.
